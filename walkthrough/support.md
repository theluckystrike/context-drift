# Support Context Drift

Context Drift has no ads and no tracking. Sponsors on GitHub pay for the time that goes into fixes and new rules.

The same developer makes free viewers for PDF, CSV, Excel, Parquet, Word, PowerPoint, HDF5 and model tensor files. The command "Context Drift: More free viewers" lists them and installs only the one you pick.

To hide these links, turn off the setting `contextDrift.showSupportLinks`.
